# 🧮 Nested Shapes Viewer

An interactive browser-based tool for drawing and manipulating nested geometric shapes. Designed for precision layout, rotational symmetry, and full control over shape parameters.

---

## 🎯 Features

- 🔷 Dual shape control: Configure Shape A and Shape B independently
- 🔢 Customizable sides: Select number of polygon sides (e.g., triangle, hexagon, octagon)
- 📐 Size & position sliders: Adjust horizontal/vertical placement and scale
- 🔄 Rotation control: Rotate each shape independently for layered symmetry
- 🧩 Nested rendering: Visualize overlapping shapes with full parameter control
